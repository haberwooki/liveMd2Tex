# Markdown-to-PDF test documents: sources and licences

Test inputs only; none of these files ships in the extension package. All were written by this project for the
Markdown-to-PDF tests (docs/DESIGN.md#testing) and are dedicated to the public domain (CC0 1.0). The names in them are invented.

| File | Exercises |
|---|---|
| `notes-unicode.md` | the XeTeX notes template and its font fallback: check marks, arrows, Greek, sub- and superscripts, box drawing in code, script letters in code and math, an emoji a font has and one that none has |
| `accented-names.md` | XeTeX in Latin Modern for letters pdfLaTeX builds from two parts (ė, ū, ī, ņ) |
| `cover-letter.md` | the example preset's letter mode on engine "auto" |
| `biblatex.md`, `refs.bib` | the biblatex mapping on bibtex8 |
| `unsupported.md` | one plain warning per unsupported construct |
| `tex-error.md` | a TeX error shown on its Markdown line |
