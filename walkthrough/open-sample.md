# Open a sample

You need no TeX installation. The TeX engine and its packages came with the extension, and nothing is
downloaded now.

1. Click **Open a sample** on the left.
2. Choose a folder, such as your Documents folder. A new folder called `article` is made inside it. If that
   name is taken, it is called `article-2`, and so on. Nothing already in the folder is changed.
3. The new folder holds `main.tex` and `references.bib`. `main.tex` opens, and its PDF appears beside it.

The first PDF takes a few seconds, because the engine starts. The next ones are quicker.

If you have not trusted the folder (VS Code's Restricted Mode), the extension asks once before it compiles.

Later, run **New document from template** from the Command Palette (Ctrl+Shift+P, then type "template"). It
offers more starting documents: a report or thesis, slides, three journal classes, and Markdown documents.
